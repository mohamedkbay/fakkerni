# iOS companion

Mode: Operate. The user's existing assistant design and workflows are the visual authority; this is a native port, not a redesign.

## Direction contract

THESIS: Open on the assistant. Capture a short spoken task, review one editable draft, and approve it.

OWN-WORLD: Inherit the near-black/white neutral palette, Cairo type, silver wire sculpture, existing vector mark, and actual Morphicons frame assets. No yellow or emoji. Native navigation, sheets, forms, and Dynamic Type remain usable.

STORY: First choose an assistant name and appearance; then hold the microphone or type. The review sheet exposes the task, event date/time, contact, and the one-hour alert. Settings has only identity, language/theme, AI connection, sound, and notification status. No test controls appear in the release app.

PROVIDER RETURN: The user explicitly prioritized connecting a provider account and returning from its website. Offer official account creation/sign-in in the system browser, return to key entry on browser Done or dismissal, verify before activation, and show a completion action that closes the setup flow. Existing key holders skip the browser. Do not imply OAuth or mark a browser visit as a successful connection.

FIRST VIEWPORT: A navigation title/provider entry above a centered animated silver orb, a short status message, and bottom recording controls; keyboard and reminders remain accessible. Dark and light variants share the composition.

FORM: Precisely specified port of the established Android surface; no concept seed applies. Native iPhone and iPad layouts use a navigation stack and focused sheets.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
