# Fakkerni v1.5.0

## Highlights

- Dedicated AI connections page for Groq, OpenAI, and Gemini. Keys are verified before being encrypted and saved. Previously connected providers activate with one tap; at most one provider is active.
- Gemini 3.8 Flash can transcribe the recording and extract a reminder draft in a single audio request. The draft still requires user review and approval.
- Two original alert sounds, Chime and Pulse, with in-app selection and playback previews. Each has a separate Android notification channel so the selected tone works after the screen is locked.
- The assistant has a direct provider chip. Settings now shows only the active AI status instead of inline key management.
- README and release documentation are in English.

## Verification

- `:app:testDebugUnitTest`, `:app:assembleDebug`, and `:app:lintDebug` passed: 36 unit tests, no blocking lint errors.
- The two WAV files were generated from the checked-in script and verified as mono 24 kHz, 16-bit PCM.
- No Android emulator system image was available on the build machine. Voice capture, provider connectivity with a real key, in-app sound preview, and lock-screen sound must be verified on a device. The 10-second test is provided for that purpose.

## Security and compatibility

- Existing Groq and OpenAI encrypted key files are unchanged; Gemini receives its own encrypted file. No secret is checked into the repository.
- User reminders and manual entry are unchanged. AI does not auto-schedule a reminder.
- Provider key verification checks authentication, not permission to use a particular speech or text model.
- Published APKs use the same local development signing certificate as v1.4.0 for in-place updates; this is not a Play Store signing setup.
