# Fakkerni v1.5.1

## What's new

- Replaced the two generated tones from v1.5.0 with the nine MP3s supplied for this project. Each was re-encoded as mono 24 kHz / 48 kbps; together they add about 148 KB before APK compression.
- Added clear Arabic and English names, an in-app preview, and an Android phone-sound picker.
- Bundled tones are served through stable app content URIs so notification-channel sounds continue to resolve across APK updates. A selected phone tone gets its own channel; the app never tries to change the sound of an existing channel.
- Existing reminder data, AI keys, and in-place update signing are unchanged.

Download `fakkerni.apk` below. SHA-256: `ff92cb584257bfc58d1737a5d54949f3448c841e3f55610f3233d0f475bd4a41`.

## Verification

- All 38 unit tests passed. Debug and release builds succeeded. Android Lint completed with no errors (49 warnings, including the intentionally exported provider that serves only packaged sounds).
- Android device playback and lock-screen behavior still require a real-device check with **Settings → Test in 10 seconds**. No emulator system image is installed on the build machine.
