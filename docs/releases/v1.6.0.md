# Fakkerni v1.6.0 — iOS companion

This update adds a native **iPhone and iPad app** (iOS 16+) alongside Android. The Android APK attached to this release is the unchanged, previously verified **v1.5.1** build.

## iOS features

- Arabic-first onboarding, assistant naming, English digits, Cairo typography, and dark/light appearance.
- A native animated silver assistant and actual Morphicons frames; hold to record, release to analyze, or type instead.
- Groq, OpenAI, and Gemini connections with Keychain storage and exactly one active provider. Arabic/Libyan transcription and structured drafts always require approval.
- Local contact search in Arabic, English, and digits. Ambiguous matches stay a user choice; the address book is never sent to AI.
- Editable reminders, local persistence, completion/deletion, call actions, and notifications normally one hour before the event.
- The same nine supplied tones in iOS-compatible CAF format, the default system sound, and a 10-second notification test.
- A checked-in Xcode project, core/API tests, native UI tests, and GitHub-hosted macOS build automation.

## Downloads and signing

- **`fakkerni-ios-source.zip`**: Open `ios/Fakkerni.xcodeproj` on a Mac with Xcode 16+, select your own signing team, and run on your iPhone. A free Personal Team requires rebuilding/reinstalling after 7 days.
- **`fakkerni-ios-unsigned.ipa`**: A generic iOS device build for signing by a developer. It **cannot be installed directly from GitHub** and includes no Apple signing certificate or provisioning profile.
- **`fakkerni.apk`**: Android v1.5.1, unchanged.

See the [iOS setup guide](https://github.com/mohamedkbay/fakkerni/blob/main/ios/README.md). This release creates no App Store or TestFlight listing. iOS reminders and credentials are independent of Android; there is no automatic data transfer.

## Verification

Native Xcode build, XCTest, Simulator UI test, and screenshot results will be recorded here before publication.

Real-device microphone quality, actual AI account access, phone calls, and lock-screen sound delivery still require an iPhone check. Notifications obey iOS permissions, Silent Mode, Focus, and volume; there is no Critical Alerts entitlement. iOS offers the default system notification sound rather than Android's phone-tone browser. The app allows 60 upcoming reminders, reserving space for the test notification.
